## 1. 案例概述  
### 1.1 问题描述  
- 仿真目标：利用结构力学模块>电磁-结构相互作用>压电模块>压电驱动下剪切梁的变形和应力  

### 1.2 涉及物理场  
```python  
# 使用的COMSOL模块（示例）  
1. 固体力学（Solid Mechanics）  
2. 静电（es） 
3. 多物理场耦合：力电耦合，压电效应（pze）  
```

## 2. 模型搭建  
### 2.1 新建模型  
```  
模型类型：3D
研究类型：稳态
```  

### 2.2 几何建模

| 变量名 | 值  | 说明       |

## 6. 常见问题  
❓ **Q1：求解不收敛怎么办？**  
✅ 尝试：  
1. 检查单位是否一致  
2. 减小初始步长  

❓ **Q2：如何提高计算速度？**  
✅ 建议：  
- 使用对称边界条件  
- 简化几何特征
